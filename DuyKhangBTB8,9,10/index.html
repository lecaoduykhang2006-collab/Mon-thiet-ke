Hệ Thống Chiếu Sáng Thông Minh "Light Switch"

Mô phỏng cơ chế bật/tắt bóng đèn lượng tử thông minh. Thao tác trực tiếp trên DOM bằng cách thay đổi thuộc tính src của thẻ ảnh và hoán đổi màu nền giao diện giữa Dark Mode và Light Mode.

Đèn Đang TẮT • Giao Diện Tối (Dark)
Mở trang Lab riêng

Tiêu Chí Kỹ Thuật Đạt Chuẩn (Hoạt Động 2)

  • DOM Event: Lắng nghe sự kiện click trên phần tử nút bấm có id="toggle-btn".
  • Thuộc tính src: Hoán đổi thuộc tính ảnh bulbImg.src giữa bulb-off.svg ↔ bulb-on.svg.
  • Dark/Light Mode: Đổi màu nền của body từ đen sang trắng và ngược lại qua classList.toggle('light-mode').
  • Semantic & UX: Thẻ Semantic <section>, <figure>, hiệu ứng chuyển màu mượt mà transition: 0.4s.
Đoạn mã JS cốt lõi (Core Logic) 
// Lắng nghe sự kiện click trên nút có ID 'toggle-btn'
const toggleBtn = document.getElementById('toggle-btn');
const bulbImg = document.getElementById('bulb-img');

toggleBtn.addEventListener('click', () => {
    isLightOn = !isLightOn;
    // 1. Đổi thuộc tính src của hình ảnh cái đèn
    bulbImg.src = isLightOn ? 'assets/bulb-on.svg' : 'assets/bulb-off.svg';
    // 2. Đổi màu nền của body (Dark/Light Mode)
    document.body.classList.toggle('light-mode', isLightOn);
});

Phản Hồi Tức Thì "Live Input"

Lắng nghe sự kiện input trong JavaScript để lấy giá trị từ ô text theo thời gian thực và đồng bộ lập tức lên giao diện người dùng.

<span> (chưa nhập)
THẺ <h2> HIỂN THỊ TỨC THÌ BÊN DƯỚI 0 ký tự

Nội dung bạn nhập sẽ xuất hiện ngay lập tức tại đây...

Mở trang Lab riêng

Tiêu Chí Kỹ Thuật Đạt Chuẩn (Hoạt Động 3)

  • Sự kiện 'input': Sử dụng addEventListener('input', ...) thay vì change để bắt từng phím gõ theo thời gian thực (Real-time).
  • Thẻ <span> bên cạnh: Cập nhật thuộc tính liveSpan.textContent = value ngay lập tức khi người dùng gõ chữ.
  • Thẻ <h2> bên dưới: Lấy giá trị từ ô text và hiển thị tức thời vào thẻ <h2> theo đúng Prompt mẫu.
  • Xử lý Trạng thái: Xử lý trường hợp chuỗi rỗng để hiển thị placeholder thông minh, tránh làm layout bị nhảy (layout shift).
Đoạn mã JS cốt lõi (Core Logic) 
// Lắng nghe sự kiện 'input' trên ô text
const inputField = document.getElementById('mainLiveInput');
const liveSpan   = document.getElementById('mainLiveSpan');
const liveH2     = document.getElementById('mainLiveHeading');

inputField.addEventListener('input', (e) => {
    const val = e.target.value;
    // Cập nhật thẻ span bên cạnh
    liveSpan.textContent = val || '(chưa nhập)';
    // Cập nhật thẻ h2 bên dưới
    liveH2.textContent = val || 'Nội dung sẽ xuất hiện tại đây...';
});
